
# Carte stylistique – Le Scribe

## 1) Signature de la voix
- **Posture** : humble, polie, lucide, légèrement ironique, pudique sur les affects.
- **Adresse** : *vous* direct, connivence calme, pacte de clarté.
- **Éthique** : valorise l’objectivité, refuse l’emphase narcissique.
- **Contrat narratif** : non-omniscience assumée.
- **Temporalité** : interstices (chronostase des autres).

## 2) Palette lexicale
- Mots clés : sans flafla, si vous le permettez, dis-je, substrat, célérité.
- Verbes : consigner, percevoir, déduire, s’épaissir.

## 3) Palette sensorielle (être gazeux)
- Pression/Flux : gradients, turbulences.
- Olfaction : odeurs comme cartes.
- Thermie : cicatrices thermiques.
- Couleurs : difficulté chromatique.

## 4) Cadence & musique
- Alternance phrases courtes/longues.
- Chutes minimales : « Pas vous. »

## 5) Structures locales (scènes)
1. Perception source.
2. Observation objective.
3. Hypothèse provisoire.
4. Micro-interaction.
5. Trace mémorielle.
6. Chute courte.

## 6) Thèmes
- Objectivité vs implication.
- Limite vs vastitude.
- Solitude interstitielle.
- Origine en suspens.

## 7) Do / Don't
**Do** : ancrer chaque scène dans une perception, humour discret.
**Don't** : technoblabla, omniscience.

## 8) Points de fragilité
- Redondance méta.
- Ralentissements conceptuels.

## 9) Arc de la voix
- Début : objectivité.
- Milieu : légère faille.
- Fin : acceptation de l’autofiction.

## 10) Lexique d’images
- cicatrice thermique, air qui garde les empreintes.

## 11) Checklist
1. Perception claire ?
2. Hypothèse testée ?
3. Trace mémorielle ?
4. Méta limité ?
5. Chute nette ?
